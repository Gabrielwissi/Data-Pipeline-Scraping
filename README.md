# Data-Pipeline-Scraping
Projeto de Engenharia de Dados para extração e processamento de informações imobiliárias.

## 🛠️ Tecnologias
- **Python / Selenium:** Webscraping do site Diálogo.
- **Databricks Connect:** Execução Spark remota no Azure.
- **Unity Catalog:** Armazenamento em camadas (Bronze/Silver/Gold).
- **Git:** Versionamento de código.

## 📈 Arquitetura
O código roda localmente no VS Code, processa os dados via Cluster Databricks e armazena os resultados em Tabelas Delta.
